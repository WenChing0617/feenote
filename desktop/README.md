# 电费记账本 · 桌面版

宿舍电费记账工具。**单文件绿色程序，双击就能用**，数据存在自己电脑上的一个 JSON 文件里，
不联网、不要账号、不上传。

Windows + Python 标准库（Tkinter）写的，**零第三方依赖** —— 连导出 Excel 都是手写 OOXML，
不引 `openpyxl`。目的就一个：拿到 exe 谁都能跑，不用先配环境。

## 一、怎么用

### 拿到别人打包好的 exe

直接去本仓库的 **Releases** 页面下载最新版 `feenote-desktop-v1.5.exe`，
双击运行即可（Windows 10 / 11，64 位）。下载后想改名成「电费记账本.exe」随便改，不影响运行。
首次打开如果 Windows 弹「未知发布者」，
点「更多信息」→「仍要运行」就行 —— 这是没有代码签名的正常提示。

### 自己从源码跑 / 打包

```powershell
# 直接跑
python 电费记账本.py

# 打包成单文件 exe（需要 PyInstaller）
pip install pyinstaller
pyinstaller 电费记账本.spec
# 产物在 dist\电费记账本.exe
```

> 打包前记得先备份账本 —— 下面「五、数据存在哪」说了文件在哪。

## 二、功能

| 区域 | 能干什么 |
|---|---|
| **顶部总览** | 累计金额、笔数、房间号 |
| **明细记录** | 按日期倒序的充值列表，可按列排序、按关键字搜索；双击一条可改 |
| **记一笔充值** | 选成员、填金额（有快捷金额）、点日期选（弹出整月日历）、选支付方式、写备注 |
| **成员管理** | 新增 / 改名 / 删除。**改名会把历史记录一起改**，删人则把 TA 的记录移入回收站 |
| **回收站** | 单条恢复、单条彻底删除、一键清空。删除永远是软删除，不怕手滑 |
| **撤销 / 重做** | 任何增删改导入都能一步步退回去（Ctrl+Z / Ctrl+Y） |
| **更多导出 ▾** | TXT 文本账本 / Excel(.xlsx) / CSV / JSON 备份 |
| **复制结算单** | 一键生成「每人充了多少、合计多少」的文本，直接粘到微信群里 |
| **手机同步** | 起一个局域网小服务，让安卓版连过来对账（见下） |

## 三、和手机（安卓版）互通

两种方式，任选：

| 方式 | 适合 | 怎么做 |
|---|---|---|
| **局域网直连**（推荐） | 平时最顺手 | 电脑点顶栏「手机同步」→「启动服务」，手机连同一个 WiFi 点一下 |
| **文件互传** | 不在同一个网 | 电脑「导出 JSON 备份」→ 传到手机导入；或反过来 |

**局域网同步怎么操作**

1. 电脑上点 **「手机同步」** → **「启动服务」**
2. 面板上会显示 **服务地址**（形如 `http://192.168.1.5:8686`）和 **4 位配对码**（每次启动随机）
3. 手机上：`设置` → `电脑同步（局域网）`，填地址和配对码 → 先「测试连接」→ 再选方向同步
4. 用完点 **「停止服务」**，服务只在手动开着的时候存在

> 第一次启动 Windows 可能弹防火墙提示，**要选「允许访问」**，否则手机连不上。

**安全上说明白**：服务只在你手动开启时监听，请求必须带对 4 位配对码（不对一律 403），
数据只在手机和电脑之间跑，不经过任何外部服务器。端口默认 8686，被占用会自动往后顺延。

## 五、数据存在哪

```
<exe 所在目录>\电费记账数据.json
```

- **从源码跑**时，数据文件在 `电费记账本.py` 同目录
- 每次保存会自动往 `数据备份\` 里留一份当日快照
- 想给电脑换位置，把 **exe 和 json 一起拷走**就行（程序是绿色便携的）
- 仓库里附了一份 **`示例数据\空账本模板.json`**，想从零开始就把它改名成 `电费记账数据.json` 放过去

> 数据文件长这样：`{"app","version","room","members","memberIds","records","deleted","savedAt"}`，
> 是纯文本 JSON，随时能自己打开看、备份、拷 U 盘。安卓版用的是**同一套格式**，所以两端能互换。

## 六、开发

### 跑测试

```powershell
python 测试.py
```

目前 **339 项全通过**。测试不碰你的真实账本（会复制到临时目录再操作）。

### 其它脚本

| 脚本 | 用途 |
|---|---|
| `检查布局.py` | 无头跑一遍所有界面，检查控件有没有重叠 / 越界 |
| `验收导出.py` | 导出功能的验收：文件头、编码、行数、合计逐项核对 |
| `验证exe.py` | 启动打包好的 exe，截图并检查数据是否完好 |
| `导入初始数据.py` | 从一份现成的 JSON 批量导入历史记录 |
| `截图回收站.py` / `裁剪放大.py` | 生成 README 用的截图（弹窗） |
| `截图主窗口.py` | 生成 README 用的主界面截图。**用假数据**（房间号 A-302、成员甲乙丙丁戊、金额重排过），并且把状态栏的文件路径改成中性值 —— 真账本截图会露房间号、真实姓氏和本机用户名 |

### 几个踩过的坑（改代码前值得看一眼）

- **Tkinter 后台线程绝对不能调 `root.after()`** —— 会抛
  `TypeError: 'dict' object is not callable`，报错极具误导性。同步服务的线程得用
  `queue.Queue` + 主线程定时泵。已在主线程时则要直接执行，否则死锁。
- **改数据文件后别只看 sha256** —— `version` / `savedAt` 变了哈希就变。
  要逐字段比对（条数、金额合计、members、id 映射）。
- **PyInstaller onefile 是双进程**：`proc.pid` 是 bootloader，真实应用在子进程里。
  找窗口要按类名 + 标题，判退出也要分开看。
- **换完图标别急着喊 bug**：先确认 exe 里的图标资源真的换了
  （用 `PrivateExtractIconsW` 直接从 exe 提，不要走资源管理器），
  再去看 `%LocalAppData%\Microsoft\Windows\Explorer\iconcache_*.db` 的时间戳 ——
  十有八九是 Windows 的图标缓存在拖后腿。
